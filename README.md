# 🌍 Sustainify – Sustainable Lifestyle & Carbon Calculator

**Sustainify** is a lightweight, responsive frontend web application designed to help users understand, calculate, and lower their personal carbon footprint through daily actionable choices.

---

## 🚀 Live Demo

Check out the live website hosted on GitHub Pages:
👉 [https://priyanshu11789-maker.github.io/Sustainify/](https://priyanshu11789-maker.github.io/Sustainify/)

---

## 📌 Project Overview

Many people want to live more sustainably but don't know where to start. **Sustainify** simplifies environmental impact assessment into three main core focus areas:
- **Transport:** Commute distances and vehicle types.
- **Energy:** Home cooling, heating, and lighting habits.
- **Lifestyle:** Plastic consumption and food waste management.

Users answer a quick interactive questionnaire and receive instant suggestions tailored to their selections.

---

## ✨ Features

- ⚡ **Pure Client-Side Performance:** Loads instantly with zero server dependencies or backend latency.
- 🎨 **Modern Visual Interface:** Styled with smooth transitions, custom dark theme, dynamic CSS backgrounds, and glassmorphism elements.
- 📱 **Fully Responsive Design:** Seamless layout across desktop, tablet, and mobile views.
- 📊 **Instant Eco-Feedback:** Calculates inputs and displays immediate improvement tips on the result page.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure across landing, calculator, and result pages.
- **CSS3 (`forest.css`):** Custom UI styling, animations, responsive layouts, and visual overlays.
